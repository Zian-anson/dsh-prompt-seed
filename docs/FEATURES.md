# 功能清单（0.21.1）

## 产品功能

| 功能 | 行为 | 自动验证 |
|---|---|---|
| ✦ 优化 | 主动补必要细节；保留目标、事实、范围与授权；换一版使用本轮原文 | 模型请求、调用次数、按钮/写回行为 |
| 输入框入口 | 空白显示水晶球，有内容显示优化；状态提示精简，其他操作按需收进 ⋯ | 图标切换、状态文案、后台取消与取回 |
| 🔮 水晶球 | 独立任务；预测用户可能的回复；无依据不填入 | 上下文、空会话、流式/旧 JSON |
| 独立任务 | 会话＋kind 隔离；取消/消费互不影响 | Host、控制器、真实 socket |
| 草稿安全 | 版本/会话/阶段/引用/附件校验；待取预览、明确替换 | 编辑后改回、切换、刷新、提交失败 |
| 撤销 | 优化原文保留到成功发送；预测仅未编辑候选可撤回 | 控制器与实际组件事件 |
| 新会话 | 有 ID 不创建；无 ID 先生成再创建/绑定，不抢导航 | 模拟宿主操作及单调用断言 |
| 引用 | 语义写回；无法无损重建只预览；附件保持 | 引用偏移、丢失、重复、新增引用 |
| 生命周期 | 十分钟内存 TTL；显式取消；重启清掉旧转圈 | 过期、断流、取消与重建实例 |
| 兼容 | 旧 API 地址/非流式 JSON/模板覆盖不变 | 契约测试 |
| 安全 | 回环 peer、Host、Origin、POST、JSON、64KB 请求上限 | 真实 socket |

不引入路由模板表、语义审判、修复调用、隐藏重试或运行时依赖。0.21.1 起支持 `ui.button: false`：外部优化 UX 接管 ✦ 入口时只隐藏内置优化按钮（客户端探测 status，失败时按显示处理）；空输入的预测水晶球仍由本插件提供。

| 真实模型 | 30 条改写＋10 条预测；结果见验收记录 |

## 质量验收

- 有优化空间的改写样本至少 80% 有具体信息增益；准确原文可不变。
- 逐条记录增益与失真；换同义词、客套、套话不算改善。
- 预测按用户口吻和对话合理性评阅，不强求“有用下一步”。
- 优化、预测分别统计非零调用 p50 ≤3 秒、p95 ≤8 秒，超标如实记录。
- 真实界面必须检查主图标切换、生成、草稿操作、撤销、切换恢复、并发编辑与引用保留。
